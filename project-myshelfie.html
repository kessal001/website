MyShelfie

A distributed, multiplayer implementation of the My Shelfie board game, developed by a four-person team for the Software Engineering final project at Politecnico di Milano.

View repository ↗
Role
Software engineer · team of four
Stack
Java 19 · JavaFX · Maven
Architecture
Client–server · RMI & sockets
Result
30L/30

The challenge

A board game becomes a distributed system.

Recreating the rules was only one part of the assignment. The application also had to coordinate concurrent matches, remote players, state changes and disconnections while supporting different network protocols and user interfaces.

The approach

Separate domain, communication and presentation.

The team structured the application around a client–server architecture with shared game logic, event-driven flows and interchangeable communication and interface layers.

C

Engineering scope

Beyond the basic game requirements

  1. 01

    Multiple games

    Host concurrent matches and keep each game’s players and lifecycle isolated.

  2. 02

    Resilient clients

    Handle disconnections and reconnections while preserving the active match.

  3. 03

    Two protocols, two UIs

    Support Socket and RMI networking alongside JavaFX and terminal interfaces.

  4. 04

    Test & document

    Use Maven, JUnit, JaCoCo, UML and JavaDoc across a collaborative codebase.

Presented in June 2023 ahead of the official deadline, the project received the highest grade with honours and remains a record of the team’s engineering process.

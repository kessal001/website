parquet_info

A terminal-first inspector for understanding Parquet files quickly—before opening a notebook, launching a data platform or writing exploratory code.

The problem

Exploration often starts with too much ceremony.

A Parquet file may arrive without context. An analyst first needs dimensions, columns, types, representative values and possible quality issues; this should not require a notebook or a heavier BI environment.

The approach

Start cheap, then narrow the question.

The tool begins with lightweight schema and metadata inspection. Users can then preview rows, profile selected columns, search text values or move into an interactive browser, spending computation only where it adds information.

A

Capabilities

One tool, four levels of inquiry

  1. 01

    Inspect

    Read schema, metadata and sample rows without loading a full analytical environment.

  2. 02

    Profile

    Review nulls, distinct counts, ranges, averages and frequent values for relevant columns.

  3. 03

    Search & browse

    Find text across the dataset or inspect its contents interactively from the terminal.

  4. 04

    Automate

    Export structured JSON so the inspection can become part of a repeatable workflow.

Example workflow

From overview to evidence.

A single command combines profiling with a targeted search.

parquet-info data.parquet \
  --profile \
  --search priority \
  --format plain

A small utility built around explicit commands, readable output, tests and continuous integration.
